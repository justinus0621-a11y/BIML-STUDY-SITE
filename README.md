# BIML STUDY 홈페이지

PR 등록은 **노션**에서 하고, 열람은 **이 홈페이지**에서 하는 구조입니다.
노션에 올린 내용은 **최대 5분 안에** 홈페이지에 자동으로 반영됩니다.

```
참여자 ──(등록)──▶ 노션 데이터베이스 ──(API)──▶ /api/notion (Vercel 서버 함수) ──▶ index.html (방문자)
```

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 홈 (요약 통계, 다가오는 일정, 최근 PR) |
| `about.html` | 스터디 소개·운영 규칙·주의사항 |
| `schedule.html` | 일정 캘린더 |
| `library.html` | PR 도서관 (검색·필터) |
| `members.html` | 참여자 |
| `assets/style.css` | 모든 페이지 공통 디자인 |
| `assets/app.js` | 모든 페이지 공통 스크립트 (설정값 `CONFIG` 포함) |
| `api/notion.js` | 노션 API에서 PR·일정·참여자 데이터를 읽어오는 서버 함수 |
| `package.json`, `vercel.json` | Vercel 실행 설정 (`/about` 처럼 .html 없는 주소 지원) |
| `.env.example` | 환경 변수 예시 (실제 값은 Vercel에만 입력) |

> 대학원 수업 아카이브는 강의자료 공유 문제 때문에 홈페이지에서 제외했습니다.

## 처음 한 번만 하는 설정 (약 15분)

### 1단계. 노션 연동(Integration) 만들기
1. 노션 개발자 페이지(https://www.notion.so/profile/integrations)에 접속합니다.
2. **새 연동 만들기**를 누르고 다음처럼 설정합니다.
   - 이름: `BIML Homepage` (자유)
   - 워크스페이스: 스터디 워크스페이스
   - 유형: **내부(Internal)**
3. 만든 뒤 **기능(Capabilities)** 에서 **콘텐츠 읽기**만 켜 둡니다. (쓰기 권한은 필요 없어요)
4. **내부 연동 시크릿(토큰)** 을 복사해 둡니다. `ntn_...` 으로 시작합니다.
   - ⚠️ 이 토큰은 비밀번호와 같아요. 카톡·GitHub·index.html 어디에도 붙여 넣지 마세요.

### 2단계. 노션 페이지에 연동 연결하기
1. 노션에서 **BIML 홈 페이지**를 엽니다.
2. 오른쪽 위 `•••` 메뉴 → **연결(Connections)** → 1단계에서 만든 연동을 추가합니다.
3. 홈 페이지에 연결하면 그 아래 데이터베이스(PR 도서관, 일정, 참여자)도 함께 읽을 수 있게 됩니다.

### 3단계. GitHub에 올리기
1. GitHub에서 새 저장소(예: `biml-pr-site`)를 만듭니다. 공개/비공개 모두 괜찮습니다.
2. 압축을 푼 폴더 안의 파일과 폴더(`api`, `assets` 포함)를 **구조 그대로** 업로드합니다.
   - `.env` 파일은 만들지도, 올리지도 마세요.

### 4단계. Vercel에 배포하기 (무료)
1. https://vercel.com 에 GitHub 계정으로 로그인합니다.
2. **Add New → Project** → 3단계에서 만든 저장소를 선택합니다.
3. Framework Preset은 **Other** 로 둡니다.
4. **Environment Variables** 에 다음을 입력합니다.

   | 이름 | 값 |
   |---|---|
   | `NOTION_TOKEN` | 1단계에서 복사한 토큰 |
   | `PUBLIC_FILES` | `false` (발표자료 파일을 공개하려면 `true`) |

5. **Deploy** 를 누르면 `https://biml-pr-site.vercel.app` 같은 주소가 생깁니다.

### 5단계. 마무리
- `assets/app.js` 맨 위 `CONFIG` 의 `labHomepage` 를 **연구실 홈페이지 주소**로 바꿉니다. GitHub에서 수정하면 Vercel이 자동으로 다시 배포합니다.
- 연구실 홈페이지 메뉴에 4단계에서 받은 주소를 링크로 걸면 끝입니다.

## 운영하면서 알아둘 것

- **새 PR 등록**: 지금처럼 노션 PR 도서관이나 개인 공간의 "내 PR 기록"에 추가하면 됩니다. 5분 안에 홈페이지에 반영돼요.
- **일정**: 노션 일정 캘린더에 추가하면 홈페이지 캘린더와 "다가오는 일정"에 표시됩니다. 종류를 `PR 발표`로 고르면 상단의 "다음 PR 발표 D-n"에도 나타나요.
- **발표자료 공개 여부**: 기본값은 비공개입니다. 홈페이지에는 🔒 표시만 나오고 파일은 노션에서만 볼 수 있어요. 교수님과 상의해서 공개하기로 하면 Vercel 환경 변수 `PUBLIC_FILES` 를 `true` 로 바꾸고 다시 배포하세요.
- **소개·규칙 문구**: 자주 바뀌지 않는 부분이라 `about.html` 에 직접 적어 두었습니다. 문구를 바꾸려면 이 파일을 수정하세요.
- **빈 행**: 노션에서 제목이 비어 있는 행은 홈페이지에 표시되지 않습니다.
- **노션 칸 이름을 바꿨다면**: `api/notion.js` 위쪽 `P` 객체의 이름도 똑같이 바꿔야 합니다. (예: `논문 제목` → `제목`)

## 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| 홈페이지 위쪽에 "노션 데이터를 불러오지 못해…" 노란 안내가 뜸 | 괄호 안 메시지를 확인하세요. 아래 항목 참고 |
| `NOTION_TOKEN 환경 변수가 설정되지 않았습니다` | Vercel 환경 변수에 토큰을 넣고 다시 배포 |
| `Notion API 404` / `object_not_found` | 2단계(연결)를 안 했거나, 데이터베이스를 다른 페이지로 옮김. 연동을 다시 연결하세요 |
| `Notion API 401` | 토큰이 틀렸거나 재발급됨. Vercel의 `NOTION_TOKEN` 을 새 값으로 교체 |
| 특정 칸이 비어 보임 | 노션 칸 이름이 바뀜 → `api/notion.js` 의 `P` 수정 |
| 데이터베이스를 새로 만들었음 | 노션에서 데이터베이스 `•••` → 데이터 소스 관리에서 ID를 복사해 `NOTION_PR_DS_ID` 등 환경 변수에 입력 |

## 로컬에서 미리보기
`index.html` 을 더블클릭해서 열면 (다른 페이지로도 이동 가능) **예시 데이터**로 화면을 미리 볼 수 있습니다. (실제 노션 데이터는 배포 후에 표시됩니다)
